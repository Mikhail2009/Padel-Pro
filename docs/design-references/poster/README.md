# Референсы постера: Court Atmosphere (Этап 2)

Три вертикальных изображения в этой папке (`court_atmosphere_1.png`, `court_atmosphere_2.png`, `court_atmosphere_3.png`) являются визуальными референсами для будущего шаблона постера **Court Atmosphere** (этап 2).

## Ключевые визуальные элементы референса
- Ночной падел-корт с сетчатыми и стеклянными ограждениями на фоне ночного неба и деревьев.
- Яркие прожекторы по краям корта с мягким свечением.
- Синее покрытие корта и сетка по центру.
- Чёрно-лаймовая ракетка и лаймовый падел-мяч в нижней части кадра.
- Лаймовые диагональные акценты по углам композиции.

## Примечания для реализации на этапе 2
- Логотип **PADEL PRO** в шапке будет отрисовываться программно (`PADEL` — белый, `PRO` — лаймовый, фирменный знак слева).
- На текущем этапе (Этап 1) изображения не подключаются к UI и не размещаются в ресурсах/assets приложения; старые цифры, таймер и счёт на референсах не используются, а чистый фон будет подготовлен отдельно на этапе 2.
